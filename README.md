# Vyshnavi Devi Vaddi – Portfolio

Static portfolio site (HTML, CSS, JS). No build step.

## Deploy on GitHub Pages
1. Create a repo (e.g. `vyshnavidevi-123.github.io` or `portfolio`) and push these files to `main`.
2. Repo **Settings → Pages → Deploy from branch → main / (root)**.
3. Your site goes live at `https://<username>.github.io/`.

## Structure
- `index.html` sections: Home, About, Skills, Projects, Experience, Education & Certifications, Contact
- `style.css` theme (colors are CSS variables at the top)
- `script.js` skills/projects/experience data (edit the arrays at the top)
- `assets/` profile photo (unedited) and resume
